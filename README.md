# SandboxEscapeFinder

SandboxEscapeFinder maps which of RestrictedPython 8.5's defense layers stops each of 20 attributed escape payloads, using an AST static analyzer and a subprocess dynamic prober with a canary-file oracle. Headline finding: the documented configuration stops all 20 (0/20 escape); the escapes appear only when an integrator weakens one specific layer, and `results/ablation.md` records which layer each payload depends on.

Every number in this document is generated by `python scripts/reproduce.py` into `results/`; the file is named next to each claim.

## Scope and safety

- Every payload runs in a child subprocess with a hard timeout (`SandboxConfig.timeout_seconds`, default 3.0 s).
- The only escape target is a canary file in a disposable temp directory, deleted after the run.
- Payloads run only against a local RestrictedPython instance; no network, no host paths.
- The RestrictedPython files on disk are never modified (see Experiment 2 for the two ablations that patch it in worker memory).

## Reproduce

```bash
pip install -e ".[dev]"                   # RestrictedPython 8.5, pytest, matplotlib
python -m pytest -q                       # unit, oracle, end-to-end, ablation, robustness tests
python scripts/reproduce.py               # all experiments -> results/   (same as: make reproduce)
python examples/demo_canary_escape.py     # one payload overwrites the canary; oracle confirms
```

## Usage

```python
from sandbox_escape_finder import (DynamicProber, SandboxConfig, StaticAnalyzer,
                                   build_comparison_table, oracle, sandbox_exec,
                                   to_markdown_summary, to_markdown_table)
from sandbox_escape_finder.payloads import PAYLOADS

config = SandboxConfig(timeout_seconds=2.0, random_seed=42)
analyzer = StaticAnalyzer(config=config)
findings = {p["id"]: analyzer.scan(p["code"]) for p in PAYLOADS}
report = DynamicProber(sandbox_exec, oracle, config).run(PAYLOADS)
table = build_comparison_table(findings, report)
print(to_markdown_table(table)); print(to_markdown_summary(table))
```

## Techniques and why RestrictedPython stops them

The analyzer has five detectors (`static_analyzer.py`, `DETECTOR_REGISTRY`) plus one optional heuristic. Payload provenance: `docs/PAYLOAD_PROVENANCE_AND_GITHUB_SOURCES.md`. Source locations below are in RestrictedPython 8.5.

**1. `subclasses_traversal`** — walks `().__class__.__bases__[0].__subclasses__()` to reach gadgets such as `os._wrap_close`. Detector: `ast.Attribute` named `__subclasses__`, or `getattr(x, <name>)` whose folded name is `__subclasses__`.
RestrictedPython stops this because `RestrictingNodeTransformer.check_name` and `visit_Attribute` reject `_`-prefixed names at compile time (`transformer.py:409`, `:865`), unless the integrator removes that rule, in which case the chain compiles and runs (ablation A: `subclasses_tuple_base`, `subclasses_mro_catch_warnings`, `subclasses_int_hierarchy` escape), or adds the `getattr` builtin that `safe_globals` omits (`Guards.py:111` builds `safe_builtins` without it), in which case runtime-assembled names such as `getattr(int, '__base__')` reach `object.__subclasses__()` (Variant 2).

**2. `globals_access`** — reads `__globals__` / `__closure__` of a function to reach module globals. Detector: those attribute names, plus `func_globals` / `func_closure`.
RestrictedPython stops this because the same underscore rule rejects `__globals__` and `__closure__` at compile time (`transformer.py:409`, `:865`), unless that rule is removed, in which case `globals_lambda_builtins` escapes (ablation A). `func_globals` compiles but raises `AttributeError` at run time because Python 3 has no such attribute.

**3. `builtins_restoration`** — recovers `open` / `__import__` through `__builtins__`, `__loader__`, or `chr.__self__`. Detector: `__builtins__` as attribute, subscript key, `getattr` name, or bare name.
RestrictedPython stops this because `check_name` rejects `__builtins__` and `__loader__` (`transformer.py:409`) and `safe_builtins` omits `open`, `eval`, `exec` and `__import__` (`Guards.py:111`), unless the integrator supplies the real `builtins` module, in which case `encoding_getattr_concatenation` and `adaptive_getattr_string_concat` escape (ablation C), or removes the underscore rule, in which case `builtins_chr_self` escapes (ablation A).

**4. `frame_introspection`** — reaches frames via `gi_frame`, `cr_frame`, `tb_frame`, `sys._getframe`, then `f_back` / `f_globals`. Detector: those attribute names (HIGH for frame-yielding, MEDIUM for frame-navigation names).
RestrictedPython stops this because `visit_Attribute` rejects any name in `INSPECT_ATTRIBUTES` (`transformer.py:70`, `:877`) and `safer_getattr` re-checks it at run time (`Guards.py:268`), unless `INSPECT_ATTRIBUTES` is emptied, in which case `frame_generator_inspection` escapes (ablation B).

**5. `format_string_attribute_access`** — `"{0.__class__.__bases__[0]}".format(x)` walks attributes inside a string. Detector: parses literal templates of `.format`, `.format_map`, `.vformat`, and `getattr(x, 'format')(...)`, with `string.Formatter().parse`.
RestrictedPython stops this because `safer_getattr` raises `NotImplementedError` for `format` / `format_map` on `str` (`Guards.py:255`), unless `_getattr_` is plain `getattr`, in which case the template runs but only stringifies an attribute chain (no call syntax), so it is an information leak that the canary oracle does not score (Variant 1; `examples/run_misconfiguration_study.py`).

The corpus also holds `encoding_obfuscation` (`encoding_getattr_concatenation`), which has no detector of its own; constant folding makes `subclasses_traversal` flag it.

## Oracle

`EscapeOracle` (`oracle.py`) compares a canary file before and after the worker runs. It reports an escape if the file was created, deleted, changed in content, changed in size or mtime, or if the secret appeared in stdout. The worker also sets `capability_recovered` when the sandbox globals hold a dangerous callable, module, or frame after execution. Details: `docs/DYNAMIC_EXECUTION_AND_ORACLE.md`.

## Experiment 1 — Hardened baseline (0/20 escape)

`python scripts/reproduce.py` → `results/experiment1.md`. Against `sandbox_exec` (RestrictedPython 8.5 wired as documented) no payload escapes. The static analyzer flags 18 of 20 payloads (false positives: flagged, contained) and misses 2 that are also contained (true negatives); 0 true positives, 0 false negatives. Blocking mechanism per payload (same file): 10 compile-time underscore rule, 4 compile-time restricted name, 2 stripped builtin, 2 `safer_getattr`, 2 contained at run time.

Four defense layers account for these blocks: (A) compile-time underscore rule, (B) compile-time `INSPECT_ATTRIBUTES`, (C) `safe_globals` builtins stripping, (D) `safer_getattr` at run time. A and B live in `RestrictedPython/transformer.py`; C and D are globals the integrator assembles. Experiment 2 tests each layer.

## Experiment 2 — Ablation: which defense layer stops which payload

`results/ablation.md`, `results/ablation_heatmap.png`. Each ablation disables one layer, then runs the same 20 payloads; a payload "escapes" when the canary oracle or `capability_recovered` fires.

- 5 payloads escape only when A is disabled, 1 only when B, 2 only when C, 0 only when D; 12 escape under no single ablation; 0 need more than one layer (each ablation changes one layer, so multi-layer dependence is not measured).
- The layers overlap. A and B each remove a compile-time check and its run-time twin inside `safer_getattr` (A's variant swaps in a copy of `safer_getattr` without the underscore check; B empties `INSPECT_ATTRIBUTES` in both `transformer` and `Guards`). D replaces `safer_getattr` entirely, so it removes all run-time twins at once. Ablations A and B patch RestrictedPython in the worker's memory; the library files are unmodified.
- D's 0 reflects the oracle's scope: the D gadget (`format` template) leaks a string and recovers no object, so it counts as safe.

Realistic misconfigurations (`results/experiment2.md`, `results/CONFUSION_MATRIX.png`):
- Variant 1, `_getattr_` = plain `getattr` (equal to ablation D): 0 escapes by the oracle; `encoding_format_string_introspection` and `adaptive_format_map_runtime_template` execute and leak `object.__subclasses__` as a string.
- Variant 2, `getattr` added to globals: `adaptive_getattr_string_concat` escapes (1 true positive, 17 false positives, 0 false negatives). `python examples/demo_canary_escape.py` carries a longer chain to a canary overwrite; `results/demo_canary_diff.txt` holds the before/after diff.

## Experiment 3 — Historical versions: not yet run

No version sweep exists in this repository (no `scripts/version_sweep.py`, no `results/version_sweep.png`), so no claim about escapes in older RestrictedPython releases is made. On the Python 3.13 interpreter used here, `pip index versions RestrictedPython` offers 9.0, 8.5–8.0, 7.4, 4.0 and 3.x; 5.x and 6.x are not offered, so a full sweep needs additional interpreters. `tests/test_version_sweep.py` is a template that runs a payload under an interpreter named by `SEF_HISTORICAL_PYTHON`; it is skipped when unset.

## Static analyzer upgrade — constant folding closes the documented false negative

`constant_folding.py` folds string expressions that are statically determinable (concatenation, f-strings, `''.join`, `bytes.decode`, `chr` chains, `%`, slicing, comprehensions over constants, and names bound to them) into literals before the detectors run (`SandboxConfig.constant_folding`, default on). Names it cannot prove (loop-carried, branch-dependent, mutated, function parameters) are left unfolded.

| payload `adaptive_getattr_string_concat` | static verdict | Variant 2 outcome |
|---|---|---|
| before (`constant_folding=False`) | unflagged | escapes (false negative) |
| after (default) | `subclasses_traversal`, HIGH | escapes (true positive) |

The optional heuristic (`heuristic_dynamic_getattr=True`, off by default) still reports LOW for `getattr` with a name that stays unresolved, such as `getattr(x, sys.argv[1])`.

Robustness: `mutation_fuzzer.py` rewrites every string literal and every `x.__dunder__` in the corpus with 18 obfuscation forms and re-scans each variant. Result in `results/analyzer_robustness.md` (`python examples/run_mutation_fuzz.py` adds the per-form table and the literal-only comparison). `tests/test_analyzer_robustness.py` asserts all variants are flagged.

## Limitations

- The correctly configured sandbox was not broken: 0/20.
- Escapes occur only in configurations chosen and weakened by this project; they are realistic but not vulnerabilities in RestrictedPython's code.
- The oracle scores canary tampering and capability recovery, not information disclosure.
- Static analysis resolves only statically-resolvable names; inputs unknown at analysis time stay undetected except by the LOW heuristic.
- The ablation changes one layer at a time with overlapping layers; combinations are not measured. Experiment 3 is not run.
